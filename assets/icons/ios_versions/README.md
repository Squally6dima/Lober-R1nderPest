# iOS version icons

Кидай сюда иконки версий iOS.

Рекомендуемый формат:
- PNG или SVG
- квадратный размер
- прозрачный фон
- например: `ios_17.svg`, `ios_18.svg`, `ios_26.svg`

Примеры:

`assets/icons/ios_versions/ios_17.svg`
`assets/icons/ios_versions/ios_18.svg`
`assets/icons/ios_versions/ios_26.svg`

Сейчас основной preview использует отдельный badge:
`assets/icons/ios17_badge.svg`

При дальнейшей привязке по версии приложение сможет автоматически выбирать нужную иконку из этой папки.
