# iOS version assets

Put iOS version files used by the application in this directory.

Recommended structure:

assets/
└── ios/
    ├── 26.6.2/
    │   └── <iOS files here>
    └── README.md

Create one subfolder per iOS version, for example:

assets/ios/26.6.2/

Do not rename the version folder; use the exact iOS version string.
